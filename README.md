# LINTU vs LINTU - Bird species comparison tool

=== WORK IN PROGRESS === 

This project is designed as a helper tool for birders trying to tell apart similar looking species. Compare pictures, sizes, appearance details, behavior, habitats, calls, and more.

Inspired by the marsh sandpiper, the green sandpiper, the wood sandpiper, and the common greenshank, and my inability to tell them apart.

## Status

The current version is a base MVP with a basic search and species data views using mock data.

## Set up

This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/app/api-reference/cli/create-next-app). Bird data is compiled using the [BirdNET+ Taxonomy](https://github.com/birdnet-team/birdnet-taxonomy) pipeline. Following are the steps needed to take to run the project.

### Install libraries

Install libraries with:

```bash
npm install
```

### Birdnet Taxonomy setup

Clone and set up [BirdNET+ Taxonomy](https://github.com/birdnet-team/birdnet-taxonomy) in the project's root folder. Follow the setup described in its README.

In case of issues with .venv setup, try the following instead:

```bash
git clone https://github.com/birdnet-team/birdnet-taxonomy.git
cd birdnet-taxonomy
python3 -m venv .venv
source .venv/scripts/activate
pip install -r requirements.txt
```

#### Collectors

First run the AviList collector. The .csv file generated here serves as the project's primary data source.

```bash
python -m collectors.avilist
```

Then run the other collectors. Note that the tasks can be quite lengthy. Use `--limit n` where `n` is an integer to limit the number of species covered. Check the BirdNET+ Taxonomy README for additional flags you can use.

```bash
python -m collectors.inat --group Aves   # Can take a long time when run in full
python -m collectors.ebird --skip-names  # TBD: is this needed?
python -m collectors.wikidata
python -m collectors.wikipedia
python -m collectors.macaulay --group Aves
```

### Set up database

This project uses Prisma ORM with PostgreSQL as the database.

#### 1. Install PostgreSQL

If you haven't already, install PostgreSQL:
- Windows: Download from https://www.postgresql.org/download/windows/
- macOS: `brew install postgresql`
- Linux: `sudo apt-get install postgresql`

#### 2. Create a database

```bash
# Connect to PostgreSQL
psql -U postgres

# Create a new database
CREATE DATABASE lintu_vs_lintu;

# Exit psql
\q
```
#### 3. Set up .env

Return to the project's root folder. Create an `.env` file and edit its contents.

```bash
cp .env.example .env
```
Update the credentials in `DATABASE_URL`
Update `AVILIST_FILE_NAME` to match the one generated by the collector, which can be found in `birdnet-taxonomy/raw_data`.

#### 4. Set up the Prisma database

Create and seed the database with:

```bash
npx prisma generate
npx prisma db seed
# Add limit flag to cap number of species created, e.g.:
npx prisma db seed -- --limit 1000
```

#### Database management

Open Prisma Studio to browse your database:

```bash
npx prisma studio
```

Visit `http://localhost:3000/api/db-test` to test if your database connection is working.

If needed, run migrations with:

```bash
npx prisma migrate dev --name <migration_name>
```

The database can be completely recreated (NOTE: all data is deleted!) with:

```bash
npx prisma db push --force-reset && npx prisma db push
```
